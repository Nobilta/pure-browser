A page worth keeping

This page exercises site preferences, printing and bookmark portability. It contains ordinary text, permission controls and a resumable download link.

Browsers should make common actions predictable. Closing a page should offer a way to reopen it, a website should ask before accessing a camera or location, and a download should retain validated bytes when it is paused. Every action should describe the state that actually occurred.

Print fixture: the browser hands page printing and PDF output to Android.

Portable bookmarks

Bookmark files make a collection portable between browsers. Importing a duplicate address must preserve the existing bookmark title and identity. Exporting must escape special characters and stay within the same documented size limits that importing accepts.

Site preferences belong to the complete origin, including protocol and port. A camera grant for one origin does not automatically apply to a subdomain or a different port. Private sessions keep their decisions separate and start previously allowed permissions in an asking state.
