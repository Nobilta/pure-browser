## 0.22.0 - 2026-11-11

这次更新主要让国内用户检查和安装更新更顺，同时改进了网页摄像头、控制台和几处日常使用细节。

一、更新更省心

国内网络可以直接从 Gitee 检查并下载更新；Gitee 不可用时会自动切回 GitHub，不需要手动选择来源。下载中断后可以从另一个来源继续下载同一版本，安装前仍会校验文件完整性和签名。

二、摄像头与网页

网页请求摄像头时，授权后直接显示实时画面，前后摄像头由网页自己选择。网页媒体的自动播放更贴近页面本意，不再额外要求点一下播放。

三、控制台

开发者工具里的网页日志和 JavaScript 执行结果支持长按选中复制，整条输出都能完整复制。

四、其他改进

数量提示会按实际数量显示单复数。证书错误提示更清楚，优先提供「返回安全页面」。繁体中文和英文文案继续对齐，主题配色保持一致。

五、问题修复

修复了长中文或 emoji 页面翻译可能因请求过大而失败、历史记录导入时写入失败会整组回滚并提示、以及书签和下载数量提示不准确的问题。

## 0.21.0 - 2026-11-07

这次更新的重点不是换一套颜色，而是重构 0.20 以来的界面体系。0.20 用灰底、阴影和层层容器划分区域；0.21 选择做减法：把网页重新放回主角，浏览器界面退到背景。

一、设计理念

纯白不是空白。我们用 1dp 瓷白微边保留卡片边界，用雪雾浅槽承载可点击区域，海蓝只留给聚焦、选中和主操作。去掉装饰性阴影，统一圆角、字号层级和 48dp 触控范围，让菜单、设置、首页、标签页、错误页和播放器看起来来自同一套系统，而不是各自拼装的页面。

二、体验上的变化

界面更轻、更安静，层级更清楚；地址栏和底部工具栏在放大字体下仍保持完整；标签预览更清晰，播放器倍速调节更顺手。整体目标是减少视觉噪音，让操作更直接。

三、问题修复

修复了网站设置等长内容抽屉滚动时误触关闭、设置页中文副标题换行、SSL 弹窗按钮被裁切、报错页和扫码页按钮高度不一致，以及菜单关闭按钮语义不清等问题。普通提示也缩短到 2 秒，带撤销操作的提示仍保留 10 秒。

## 0.20.0 - 2026-11-05

本次更新主要围绕网页音视频播放与下载、书签管理以及广告过滤体验进行了体验升级和稳定性修复。

🎬 音视频与投屏面板

• 直接播放与全格式支持：投屏面板中的「复制」按钮升级为「播放」，点击即可在新标签页直接打开；包括 .m3u8、.mpd 在内的所有嗅探资源现在都支持新标签播放与下载。
• 防盗链与登录兼容性提升：新标签播放自动沿用原网页来源信息（Referer）并正确处理跨站跳转 Cookie，大幅减少防盗链拦截；支持弹出 HTTP 登录框与 HTTPS 证书确认。
• 播放不中断：播放过程中遇到分段重新验证或偶发网络波动时，直接在原播放器内恢复进度，不再整页刷新或弹出整页报错遮挡画面；修复旧版 WebView 拖动超过 2 GB 的大视频时卡住的问题。

📥 下载体验优化

• 保护一次性下载链接：从媒体页转为附件下载，或多线程下载遇到不支持分段（Range）的服务器时，直接保存已接通的数据流，不再重复发起请求导致一次性链接失效。
• 连接状态透明可控：当附件连接因等待超时或网络设置限制而关闭时，弹窗会清晰提示原因；手动点击「重试」后会自动转为普通下载任务，支持常规暂停与断点续传。

🔖 书签管理升级

• 显示网站图标：书签列表新增本地缓存的网站图标显示（仅在浏览或收藏时本地缓存，打开书签页不会后台联网请求网站）。
• 长按拖拽排序：长按书签或文件夹即可通过左侧手柄上下拖动调整顺序，支持快速跨多行拖动与列表边缘自动滚动翻页；同时精简了书签顶栏菜单与根目录路径显示。

🛡️ 广告过滤与性能

• 减少广告闪现：在网页脚本执行前提前注入广告元素隐藏规则，有效解决网页刚打开时广告「先闪一下才消失」的问题。

## 0.17.5 - 2026-10-28

自 0.15.0 以来的稳定版汇总，主要完成阅读模式、打印和站点级设置，并集中修复外部应用跳转、书签撤销、下载失败路径和阅读模式的一批边界问题。

阅读与页面工具

• 新增阅读模式：从当前页提取正文重新排版，跟随应用明暗主题；退出后输入框内容、iframe 草稿和页面事件绑定都不会丢失。

• 新增打印 / 另存为 PDF：直接由 WebView 渲染，系统打印界面即可导出。

• 新增站点级浏览器标识（UA）：可按站点覆盖，留空恢复默认，并随设置备份迁移。

• 内置搜索引擎新增秘塔 AI 搜索。

界面

• 应用内提示统一为 Material 3 Snackbar，支持左右滑动关闭和操作撤销。

• 菜单、标签页、站点设置等底部面板加入拖拽把手。

• 菜单和设置行统一为 M3 ListItem，单行/双行高度、图标和尾部控件对齐。

• 安全状态色纳入主题，在明暗和动态取色下保持语义与对比度。

外部应用与安全

• 网页和地址栏给出的任意应用 scheme 都可以走按站点确认的跳转；确认框显示实际会打开的应用名，不再只显示协议名。

• file、content、javascript、data、ftp 等必须留在浏览器内的地址继续拒绝；外部 intent 的组件、包名和 URI 授权在启动前清理。

• 子框架或站点拒绝外部应用时，不能借外跳的 fallback 地址替换当前页面。

• HTTP(S) 校验收紧：拒绝首尾空白、非法主机字符和非法 IPv6 形式，书签导入不会因为 Rust 与 Kotlin 判断不一致而整份失败。

• 说明：显示目标应用名需要读取已安装应用清单，仅用于本次匹配；上架 Google Play 需按 QUERY_ALL_PACKAGES 政策单独申报。

书签与下载

• 批量删除和清空全部支持撤销；关闭书签面板不会丢失撤销，跨页选择也能完整恢复。

• 恢复时文件夹已删除会回退根目录；清空全部撤销不会把文件夹数量写超上限。

• 页面内生成的下载失败路径不再把失败任务标成完成；失败标记、临时文件和目标 URI 在导航、发布和重试之间保持一致。

可靠性

• 修复阅读模式在同一 URL 刷新后把旧请求注入新文档的问题；切换文档后旧请求立即失效。

• 阅读模式在 Trusted Types 页面上失败时保持原页面不变，不残留半截阅读样式。

• 过滤列表启动只读取、校验一次，MB 级快照不再重复处理。

• 补齐 IPv4 嵌入 IPv6 校验，过滤订阅、脚本资源和下载恢复可用。

• 禁用菜单行恢复无障碍 disabled、角色和开关状态；Snackbar 拖拽不会误关替换后的提示。

## 0.14.0 - 2026-10-08

### 新增

- **手动屏蔽网页内容**：长按图片或链接，面板给出「屏蔽此地址」「屏蔽此网站的资源」「仅在本页隐藏」，
  并在写下去之前把将要写入的规则原样列出来；菜单 → 手动屏蔽元素 则是直接点选页面上任意元素，
  操作栏显示选择器与它匹配的数量，可逐级扩大或缩小范围。规则都汇总在过滤设置的「我的规则」里，可逐条删除。
- **投屏面板的 ±10 秒快进 / 快退**，以及**投屏时把手机正在播的位置带过去**。
- **系统返回手势（预测性返回）**：可拖动的底部面板现在跟随返回手势，松手完成或弹回，
  而不是只在整个手势结束后才关掉。
- **下载网页在内存里生成的文件**。有些网页先自己显示下载进度、进度走完才把生成好的文件交给浏览器保存，
  这类文件只有一个 `blob:` 地址，任何 HTTP 客户端都取不到，此前只会提示「无法开始下载」。
  现在浏览器会向页面逐块索取数据，写完一块再要下一块，因此文件多大都不会整份进入内存；
  确认框显示网页给出的文件名与大小，中途失败或取消会清掉临时文件，且这类任务不提供暂停 / 续传 / 重新下载。
  页面创建的 Blob 在传输完成或取消时立即释放；发布失败会转成失败并清掉临时文件，而不是停在「正在保存」；
  传输期间导航到其他页面会结束旧文档的传输，切到别的标签页则不会让它卡住（后台页面的分片照常接收）。
  它和普通 HTTP 下载在取到字节之后共用同一条发布链路，因此列表、通知与打开方式只有一份实现。

### 修复

- **元素选择器选中的规则写不进去**。规则校验拒绝了含空格的文本，而选择器在找不到唯一 id / class 时
  产出的正是「祖先 > 元素」这种带空格（后代 / 子代组合符）的路径——于是一大批元素点下去时被本地隐藏了、
  提示却说无法生成规则，设置里也找不到它。现在这类选择器可以正常写入。
- **元素选择器在部分页面上会带走整个应用进程**：给已加载完成的文档迟挂消息通道、随后再改动该文档，
  会在 `libwebviewchromium` 里空指针崩溃（SIGSEGV）。通道改为在 WebView 配置时挂载，与媒体探针、
  用户脚本运行时一致。
- **选择结果与「仅在本页隐藏」不再落到别的文档上**。写入规则与执行隐藏脚本都是异步的，期间导航会把
  旧选择器 / 旧图片地址作用到新页面；两者现在都会核对文档是否仍是原来那个。
- **被系统取消的触摸不再算作一次选择**。来电、系统边缘手势或切到后台会发 `touchcancel`，此前会挑选
  手指下方的元素并写入规则，现在结束这次选择并收起操作栏。
- **页面无法再伪造元素选择器**。选择器的消息通道对页面本身是敞开的，页面可以在选择器运行时提交
  任意选择器——比如 `*`——此前会通过校验并被写成隐藏规则，选了「所有网站」还会作用到所有站点。
  通配符与 `:root` / `:scope` 这类指向整个文档的选择器现在在填写与写入两处都被拒绝。
- **「仅在本页隐藏」对响应式、懒加载与相对路径图片都无效**。选择器只匹配 `src` 属性、且用原始属性文本比对，
  用 `srcset` / `data-src` 承载地址的图片、以及 `src="/a.png"` 这类相对地址的图片按了没反应；
  长度上限也算错了对象（较长的签名图片地址会被静默拒绝）。现在按浏览器自己解析出的地址比对，
  同时保留对懒加载属性的匹配，并按实际隐藏数量给出提示。
- **规则没保存成功却仍然隐藏了元素**。写入是异步的，隐藏却是无条件的：规则达到上限或落盘失败时
  元素照样消失，刷新后又回来，与提示自相矛盾。现在隐藏挂在保存结果上。
- **元素预览承诺了规则做不到的效果**。预览用行内 `display:none!important`，保存后的规则是样式表规则，
  遇到页面自己的行内 `display:block!important` 时前者能盖住、后者盖不住。预览改为注入与引擎同一条样式表规则。
- **路径里带 `$` 的地址规则会被引擎丢弃**。引擎在最后一个 `$` 处切分并把后面读成选项
  （`banner$1.png` 会读成选项 `1.png`），整条规则按「不支持」丢掉，而校验却接受它。生成与校验现在都拒绝。
- **投屏跳转失败会说清楚**（设备拒绝 / 没报告进度各有各的话），**拖动进度条不再被轮询拉回**，
  **音量设置失败后滑块会恢复**；另外**切到另一个视频投屏不再带上当前视频的进度**，
  **旧的投送请求也不会再改掉新视频的位置**。
- **能看出这个网站到底跑了哪些油猴脚本**。菜单的「扩展与工具」区新增一行「油猴脚本」，只在本页确有脚本
  运行时写出它们的名字；脚本管理页里每个脚本也会标注「在本页运行 / 不适用于本页」。
  两处都取自**本页实际收到的脚本**，而不是按匹配规则现算，因此刚安装或刚启用的脚本不会被说成已经在本页运行，
  在面板里停用脚本后状态也会立即跟上。
- **无痕下能看到脚本在做什么**。脚本管理页顶部说明「脚本照常运行，但保存的数据只留本次会话」，
  每个脚本同时标注「在本页运行 / 不适用于本页」。
- **用户脚本的存储写入被拒绝时会得到明确回应**。此前的拒绝（脚本被停用、授权被收回、
  地址或框架不匹配、请求过载）是静默丢弃的，脚本的 Promise 会一直挂到自己的 15 秒超时，
  分不清「被拒绝」和「浏览器忙」。现在通过标识与请求号校验之后的每种结果都会被应答，
  而应答里只有这两个 ID，不携带任何凭据。
- **无痕会话的脚本数据不会留到下一次会话**。清理此前只挂在手动切换模式上：直接退出浏览器、
  同一进程再开一次无痕都不会清，脚本写入后刷新读到的还是旧值，删除的脚本其存储值也仍在内存里；
  而写入与会话边界不共用同一把锁，一次跨越边界的写入会把上一个会话的值写回来。现在开始与结束统一走一处，
  写入与会话边界原子化，范围覆盖冷启动直接进无痕、Activity 重建与菜单切换三条路径。
- **无痕下的脚本写入不会再落盘**。写入在协程里重新读取了当前模式；提交写入后立刻退出无痕，
  本来只该留在内存的值会被写进普通会话下次读取的那份文件。模式在受理写入时就固定下来。
- **普通下载重新遵守「仅非计费网络下载」**。加入页面文件下载时这一项被整体写成了 false，于是所有普通
  HTTP 下载都绕过了用户的设置。现在只有页面文件（数据已在内存、没有网络可等）免于这条限制。
- **重试后的旧传输不会再发布结果**。暂停后立刻重试会替换任务协程但保留 id 和临时目录；
  被替换的那个协程仍在收尾，会把自己的旧分片当成本任务的成果发布、标成完成，并删掉新传输正要写入的目录。
  发布、保存进度与完成更新现在都要求协程仍是该任务的所有者。
- **同一文档连续触发多次 Blob 下载时，先发出的那次不会再被丢掉**。待回答的询问此前只有一个位置，
  第二次会覆盖第一次；第一次的回答因编号对不上被丢弃，用户只看到后一个下载。现在按编号各自保留，
  每个地址也各自留到被确认，数量有上限。
- **失败、取消或中断的页面文件不再占用存储**。这类任务的临时分片不可续传，重启清理此前仍按「可恢复」
  保留下来，会一直占着磁盘；现在会连同记录一起清掉。写盘失败时也会真正停止页面侧的传输，
  否则页面会一直以为传输还在进行，同一文档里的下一次下载会被拒绝。
- **手写规则的体积计入引擎的总量上限**。此前只校验订阅列表，规则本身可以超出 32 MiB 的合并上限，
  于是规则被写入并在设置里显示，引擎却整体拒绝这份快照、规则实际不生效；现在写入前就按同样的三条上限
  （单份、总量、份数）判定并给出明确提示，超过上限时也不再无声清空（写日志），列表按规则文本去重。
- **启用订阅、导入配置都按合并后的快照预检**，不再只算订阅文件本身，也不再用导入前的旧规则去判定导入后的
  新规则；旧版本订阅的迁移同样会先过这三条上限。此前把订阅或规则开到接近上限，会保存一个引擎整体拒绝的配置，
  界面显示已启用而过滤实际停留在旧快照。删除手写规则失败时现在也会提示。
- **导出的设置文件不会再大到导不回来**。导出预算此前按字符数估算，而文件按 UTF-8 写入、
  导入端按 8 MiB 字节数拒绝，中文标题或大量站点配置就可能导出一个本机读不回的文件；现在预算按 UTF-8 字节计算，
  并在写出前用真实编码结果复核，超限时按「不拒绝、只少导」的规则继续裁剪并如实报告：先裁书签、再裁历史，
  每次至少少一行，避免只剩几行时反复裁剪却不收敛。
- **长按「链接里的图片」时，屏蔽行指向的是图片自己的地址**。此前会退回到链接本身，
  在网站自己的图库里那就是正在浏览的这个站，「屏蔽此网站的资源」等于把整页带走；现在图片地址优先，
  三行（地址、站点、本页隐藏）针对同一个请求。
- **菜单里的油猴脚本一行不再一直显示无效小字**。只有本页确实在运行脚本时才写「本页正在运行：…」，
  「无脚本匹配 / 无痕模式 / WebView 不支持」这些日常情况不再占一行——以前每次打开菜单都在解释
  “为什么没有”，会让人习惯性忽略这一行。
- **从其他应用打开网页不再顶掉当前页面**。此前 VIEW / SEND intent 直接在当前标签里导航，
  用户正在读的页面被替换掉；现在会在新标签页打开（当前是主页 / 新标签页、当前标签无网址、
  或已达标签上限时才复用当前标签），行为与其他浏览器一致。
- **关闭面板时不再播放第二段退场动画**。路由宿主自己已经把面板动画移出屏幕，之后才卸载 Dialog 窗口；
  而窗口上还挂着一个 250 ms 的退场动画，等于让一个已经空掉的窗口（连同它的遮罩）在用户看到面板消失之后
  再停留一段时间。实测窗口比 Compose 退场多活了约 370 ms。现在只有由页面自己打开、被卸载时没有 Compose
  动画可放的表面（例如设置里的选择器）才使用窗口动画。
- **页面替换时不再整块重绘**。从菜单进入设置这类「上一张面板」的透明度此前在组合期读取，
  等于让整块面板内容在那一动画的每一帧重组一次；改为只在绘制期读取。

### 变更

- **菜单重新分类**。此前顶部两组图标没有任何标题，历史记录单独占一个「浏览数据」分区，
  而「设置与工具」把脚本、扫码、开发者工具塞在一起，又与页面操作里的「桌面版网站」割裂。
  现在分为：快捷入口 / 页面操作 / 隐私与安全 / 扩展与工具，
  「网站设置」从顶部图标移入「页面操作」（它本来就在改当前网站），历史记录并入快捷入口，
  「清除浏览数据」留在「隐私与安全」而不是被归入扩展。
- **设置页重新分类**。原来的「隐私与过滤」把互不相干的东西塞在一起（无痕浏览、密码、广告过滤、
  油猴脚本、按站点规则、清除数据），现在拆成「隐私与安全」（无痕浏览、密码与通行密钥）和
  「扩展」（广告过滤、自定义规则、油猴脚本、网站设置、清除数据、导入导出），共 7 个分类；
  各分类首行的摘要也改成回答该分类自己的问题。
- **无痕模式现在也运行用户脚本**。此前无痕下脚本被整体跳过，而这恰好是最需要脚本的场景（例如
  用脚本关掉某些站点在登录页上的弹窗）。脚本本身是用户自己安装的，与页面无关，因此改为照常执行；
  真正需要留在无痕边界内的是**脚本自己保存的数据**：会话期间的 GM 值放在内存里，进入与退出无痕
  都会清空，不会写进普通模式下次会读取的那份文件。脚本本身与其启停状态仍是全局的（无痕里的启停
  会保留），这是既有行为，没有改变。

### 说明

- 预测性返回的进度只在系统边缘回滑时才有；从屏幕内滑动、键盘返回等仍是普通返回。
  正在进场或退场中的面板不接管返回手势，避免正在退出的面板被再关一次。
- 元素选择器只在 http(s) 页面可用；无痕模式下的临时隐藏写在文档里，随文档一起消失。

- 广告过滤的规则语义与 Adblock Plus 对齐：裸域规则（`||ads.com`）此前只拦后缀完全一致的地址，现在也拦以该域开头的其他主机；EasyPrivacy 里用尾点表示「任意后缀」的规则（如 `||adservice.google.`）此前完全失效，现已生效；`^` 不再把 `%` 当作分隔符，`/ads^` 不再误拦 `/ads%20foo` 这类百分号编码的地址。
- 过滤不再悄悄丢规则：订阅总量超出引擎上限时，被丢弃的行数会在过滤设置里单独显示，开发工具的过滤命中说明也会提示结论可能包含未加载的规则。地址很长的页面也不再因通配规则匹配而明显变慢（8 KB 地址由约 92 ms 降至约 1 ms）。
- 无痕下载不把下载地址的查询参数和来源页面写进应用存储：记录只保留文件名、保存位置和去掉查询参数的地址，续传用的断点文件只保留摘要；退出无痕后不能在会话之外重新下载。
- 跨会话的无痕下载记录（含从旧版本迁移来的系统下载记录）不再显示无法完成的「继续/重试」按钮，只保留查看、打开和删除。
- 页面脚本无法再借用用户脚本的存储通道：存储凭据不再随回复回传，脚本读写的对象值也不再经过页面安装的 `toJSON`；媒体播放状态按来源绑定，同一页面里的第三方 iframe 不能冒充播放器上报状态。
- 设置导入被打断时也会写完已通过校验的部分，并说明是哪个分组失败，不会再出现只应用一半又没有提示的状态；书签与历史导出读不到数据时会明确失败，不再生成看起来像空库的备份文件。
- 数据读不出来时不再被静默删除：首页快捷方式和自定义搜索引擎在解析失败时保留原值与原设置，之后仍可导出或重试。
- 地址栏搜索联想按与应用其它联网请求相同的策略逐跳校验重定向，不会把查询交给重定向指向的任意主机。
