# 0.7.0 实施记录

本轮按用户修订范围精简功能、扩大视频控制覆盖并补齐下载交互。发布包与最终验证以 [README](../README.md)
和 [模拟器报告](../EMULATOR_TEST_REPORT.md) 为准；历史提交继续保存在 `master` 的正常 Git 历史。

| 工作 | 当前实现 |
|---|---|
| 下载打开 | 完成行直接发送通用 ACTION_VIEW/content URI 与临时读取授权；由系统决定查看器或安装器，无浏览器类型分流 |
| 下载状态 | 保留进度/速度/ETA/暂停恢复，修正未知总大小的列表与通知；补充完成通知、冷启动定位和缺失文件反馈 |
| 内嵌视频 | 原视频上的单一增强层，播放/暂停/进度/倍速/静音/全屏/恢复，紧凑布局适配 160×90 |
| 控制权 | 验证控件隔离、画面边界、遮挡和命令回执；失败恢复原样，显式恢复后不自动反复抢占 |
| 全屏 | 进入前撤下内嵌层，沿用原生全屏控件，退出后再挂载单个内嵌层 |
| 功能精简 | 删除阅读/离线文章、Google Cast、本地备份恢复、双窗口，连同专用依赖、界面、资源和测试 |
| 会话保留 | BrowserSessionState 继续保留普通/私密标签跨 Activity 重建，不再持有跨窗口注册表 |
| 私密退出修复 | 每会话独立 Profile 名称，退出擦除已加载数据，失败不复用旧名称，进程启动清理遗留 Profile |
| 文档与清理 | README 为当前入口；合并重复的旧版本能力/方案文档，保留必要架构与验证依据 |

普通多标签、书签 HTML、打印/PDF、DLNA、脚本、系统凭据、PiP/后台媒体及既有隐私/过滤能力继续保留。
翻译与跨设备同步按用户决定排除；跨域脚本网络、隔离世界和完整网页归档不作为已实现功能。

本轮自动检查：321 项 Android/Robolectric、58 项 Rust、51 项 Node、619 项三语言资源检查，
以及 Rust fmt/clippy、Android lint、R8 和签名验证通过。模拟器按安装包 SHA-256 记录实际阶段，
失败及输入工具修正保留在本版验证目录，不沿用旧包结果冒充本版覆盖。

没有使用真实账号、实体 DLNA 接收器或低端真机；也没有逐站验收全部在线流媒体、DRM 和 MSE 服务。
Provider 能力与网站布局不允许接管时，恢复网站播放器是预期行为。
