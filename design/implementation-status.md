# 0.9.0 实施记录

本轮修复多标签来源页重载和跨标签返回，优化菜单/标签动画，加入 GitHub 更新并精简开发测试范围。既有源码高亮、网络分类、MD3 界面和扫码能力继续保留。发布包与最终验证以 [README](../README.md)
和 [模拟器报告](../EMULATOR_TEST_REPORT.md) 为准；历史提交继续保存在 `master` 的正常 Git 历史。

| 工作 | 当前实现 |
|---|---|
| 弹窗与来源页 | 交接后复用最近页驻留缓存，保留表单、SPA 与滚动；媒体暂停，私密/低内存遵循原清理边界 |
| 跨标签返回 | 会话内来源关系与最近访问顺序；网页历史优先，子标签关闭后返回来源，系统返回/底栏/“×”一致 |
| 应用更新 | 关于页手动检查，GitHub 正式资产直链、缓存/退避、独立下载与签名校验，用户确认后交给系统安装器 |
| 发布与测试 | 自动生成 update.json；quick/release 构建与 smoke/tabs/full 回归分开，移除 API 29 专项测试 |
| 扫码预览修复 | 按系统已旋转的缓冲区尺寸等比裁切，仅补偿显示旋转；保留系统前摄镜像，监听 180° 转屏并在关闭时注销 |
| 开发工具与性能 | HTML/JS/CSS 后台高亮、惰性源码/控制台、按选中页发布日志；网络分类/状态/搜索，导航隔离旧回执 |
| 统一 UI | 共用 MD3 标题、顶部安全间距与图层过渡，固定菜单标题，列表与单选语义一致 |
| 二维码与首页 | Camera2 + ZXing 离线相机/图片识别，网页直接访问、其他文本展示/复制；首页移除主页占位并替换刷新为扫码 |
| 菜单精简 | 删除页面播放速度入口；书签操作和列表、网站设置和全局设置使用不同图标 |
| 标签精简 | 删除最近关闭、撤销和持久化，升级清理旧存档；保留当前标签搜索、分组和批量关闭 |
| 设置窗口 | 菜单及子页面共享 Dialog，只有当前内容与返回回调替换，保留分类、选项和重建状态 |
| 页面滚动 | 所有同类表单和列表统一禁用边界拉伸，底部弹层固定位置、无拖动手柄 |
| 无效测试 | 删除打印和最近关闭测试阶段、四项过时标签单元测试及旧菜单截图断言 |
| 地址栏输入 | 建议与编辑器共用窗口；键盘、清除、补全不结束编辑；提交、页面点击与返回显式结束编辑，旋转保留草稿 |
| 系统媒体释放 | 结束、卸载、隐藏并暂停、移除、替换、离页及关闭标签后释放 token、元数据、通知与前台服务；普通暂停仍可继续；后台服务先应答启动，再有序停止，保留较新的请求 |
| 无最终消息的 frame | 每个媒体 frame 独立失效，最后一个跨域播放器被移除后无需等待另一份文档消息；正常后台播放持续刷新 |
| 画中画关闭 | 暂停原视频并停止系统媒体，即使开启后台播放也不恢复被关闭的小窗；迟到播放消息受到暂停状态约束 |
| 画中画画面 | 全屏不预留工具栏高度，宿主位于 content 容器并使用进入前窗口坐标；增强接管时抑制 WebView 旋转退出，退出接管恢复原属性 |
| 菜单返回 | 菜单只允许一个子页面，拒绝反向及过深恢复路径；路由切换销毁旧组合及返回处理，父级保留滚动状态 |
| 开发工具 | 仅保留菜单入口，删除关于页和设置搜索中的重复入口 |
| 下载打开 | 完成行直接发送通用 ACTION_VIEW/content URI 与临时读取授权；由系统决定查看器或安装器，无浏览器类型分流 |
| 下载状态 | 保留进度/速度/ETA/暂停恢复，修正未知总大小的列表与通知；补充完成通知、冷启动定位和缺失文件反馈 |
| 非全屏视频 | 删除内嵌接管代码与资源，始终保留网站原始播放器 |
| 控制权 | 验证控件隔离、画面边界、遮挡和命令回执；失败恢复原样，同一失败会话不自动反复抢占 |
| 全屏 | 按网站增强播放选择接管原视频，删除快进/后退与模式切换按钮，保留手势；退出恢复网页原控件 |
| 全屏操作浮层 | Compose 覆盖层内右对齐浮层，复用投屏列表；不创建新窗口，不改变原视频布局；退出、后台及 PiP 清理，返回优先关闭浮层 |
| 功能精简 | 删除阅读/离线文章、Google Cast、本地备份恢复、双窗口，连同专用依赖、界面、资源和测试 |
| 会话保留 | BrowserSessionState 继续保留普通/私密标签跨 Activity 重建，不再持有跨窗口注册表 |
| 私密退出修复 | 每会话独立 Profile 名称，退出擦除已加载数据，失败不复用旧名称，进程启动清理遗留 Profile |
| 旧 WebView 媒体修复 | 消息桥与文档开始注入分别检测，页面加载后仍实时回传播放状态，避免快速切后台时误暂停 |
| 文档与清理 | README 为当前入口；合并重复的旧版本能力/方案文档，保留必要架构与验证依据 |

普通多标签、书签 HTML、DLNA、脚本、系统凭据、PiP/后台媒体及既有隐私/过滤能力继续保留。
翻译与跨设备同步按用户决定排除；跨域脚本网络、隔离世界和完整网页归档不作为已实现功能。

自动检查覆盖真实 host JNI 的 Android/Robolectric 测试、Rust fmt/test/clippy、JavaScript 协议、
三语言资源、lint、R8、签名和打包后脚本一致性。数量和最终设备结果统一记录在 README 与模拟器报告。
模拟器通过真实键盘/触摸、网页遥测、系统媒体状态与截图核对行为，结果绑定安装包 SHA-256；
失败及输入工具修正保留在本版验证目录，不沿用旧包结果冒充本版覆盖。

没有使用真实账号、实体 DLNA 接收器或低端真机；也没有逐站验收全部在线流媒体、DRM 和 MSE 服务。
Provider 能力与网站布局不允许接管时，恢复网站播放器是预期行为。
