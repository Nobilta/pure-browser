# 剩余工作与验收边界

2026-09-10，当前版本 0.5.1。菜单逐级返回及快速操作的生命周期修复见 [菜单导航设计](menu-navigation-20260910.md)。
已完成按网站设置、独立网站权限、最近关闭标签、书签 HTML 迁移、
阅读/离线文章、打印/PDF、下载分段恢复和 DLNA 远端控制。元素隐藏已迁到 Rust，并完成与旧
Kotlin 的输出和性能对照，详见 [本轮复查](browser-capabilities-20260910.md)。

以下是尚未实现或尚未覆盖的能力，不能视为现有版本已经通过的结果：

| 范围 | 当前限制 | 下一步验收 |
|---|---|---|
| 实体设备与 DLNA | 已有 SOAP、状态机和请求串行测试，没有实体接收器 | 两类以上接收器验证 MP4/HLS、暂停/继续、Seek/音量、断网、设备重启、格式与鉴权失败；区分设备报告状态和实际画面 |
| 手机端性能 | 元素隐藏与网络匹配有主机微基准，缺少低端真机整页证据 | 同规则/页面录制启动、P95 请求延迟、内存、帧率及功耗；测 JNI 和注入开销后再决定新增 Rust 热点 |
| 用户脚本/扩展 | 常用 GM API 可用，完整 Tampermonkey/WebExtension、隔离世界及跨域请求未实现 | 定义脚本来源和逐能力授权，验证依赖更新、存储迁移与跨 frame，建立真实脚本兼容集 |
| 账号同步与密码库 | 无自建账号后端、跨设备同步或加密凭据库 | 独立设计端到端加密、系统密钥保护、冲突合并、撤销/恢复与数据导出；不把网页 Cookie 当作密码管理 |
| 阅读与网页归档 | 阅读保存为纯文字，文件夹书签会展开 | 根据真实使用需求加入阅读提取质量集、书签文件夹/排序、完整网页离线包；验证配额、重复导入和旧数据迁移 |
| 标签组织与多窗口 | 已有多标签搜索、关闭恢复，没有分组、跨窗口拖动和桌面式多窗口 | 先定义独立窗口生命周期、选择/恢复规则与后台内存预算，再拆分 Activity 编排 |
| 翻译、Google Cast 和独立解码 | 未内建对应服务或 SDK | 先确定隐私、服务费用、密钥/授权、语言或媒体兼容范围，以及新增依赖对 APK 的影响 |
| 自动化可靠性 | 原生/网页可访问树及系统选择器有版本差异 | 逐步增加稳定 Compose semantics 定位；保持实际触摸、结果遥测和文件校验，避免仅以按钮存在判定功能成功 |

当前两个产品 JNI 库已覆盖有明确输入边界的计算路径。Compose、WebView、SQLite、SAF、
权限和生命周期继续依赖 Android；对这些部分先找可测的瓶颈，再评估跨语言改写。
