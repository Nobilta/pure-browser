# 菜单返回与弹层生命周期（0.7.1）

## 当前导航规则

菜单是根页面，只能进入一个子页面：设置、书签、历史、下载、网站设置、开发工具或媒体选择。
设置的分类和选项由设置自身管理，完整返回路径是“选项 → 分类 → 设置首页 → 菜单 → 浏览器”。
开发者工具仅从菜单打开；关于页仅显示版本资料，设置搜索也没有重复的开发工具入口。
工具栏或视频控件直接打开的标签、投屏、倍速没有菜单父级，关闭后直接回到浏览器。

打开网页、分享、打印、应用倍速等完成操作关闭整条菜单路径。普通后台切回保留当前界面，
外部 VIEW/SEND 网址清空临时导航；配置重建保存完整来路及稳定 key。

## 页面和返回处理的所有权

- `BrowserSheetNavigation` 原子保存路由与当前 `Presentation`，仅 MENU 可以压入一个子页面。
  恢复时拒绝反向父子关系、三层路径、重复目的地或无效 key。
- 路由 key 保持稳定，用于恢复菜单滚动和父级 UI 状态；每次显示都有新的 `Presentation`，
  迟到的关闭动画回调和重复点击只能操作原页面，不能关闭后来重新显示的页面。
- `BrowserSheetHost` 只挂载栈顶。`SaveableStateProvider` 外使用 `key(route.key)`，
  使设置全屏页面与菜单 Dialog 切换时真正销毁旧组合及其返回处理，避免复用旧页面。
  父级只保存 UI 状态，不保留隐藏窗口；菜单滚动状态置于 Dialog 自身的保存注册表之外。
- 设置分类、系统返回、左上角按钮和边缘手势使用相同层级规则；管理弹层打开时停用父级返回。
  选项弹层有代次标识，过期关闭回调不能清除新选项。
- 菜单手柄使用主窗口的系统安全边距，避免拖动触发通知栏；兼容旧系统的 Dialog inset 差异。
- 退出确认使用单调时钟。菜单操作会清除之前在网页上的返回计时，只有浏览器本身连续两次返回才能确认退出。

0.7.0 基线在 Android 17 的单次系统返回与边缘返回中没有重现用户报告的“设置反复出现并卡住”。
本轮针对页面组合复用、无效来路和回调所有权进行加固，并用反复操作与窗口数量验证最终行为；
不将缺少该次设备日志的现象断言为 ANR 或唯一已复现根因。

此前 0.5.0 使用单个 `Sheet?` 覆盖菜单父级，已在旧版验证中确认设置返回后直接落到网页。
0.5.1 引入路由栈与过期回调保护；当前实现延续这些规则并限制实际导航图。
这属于 Android 窗口和 Compose 生命周期管理，保持 Kotlin 实现。

## 可重复验证

单元测试覆盖父子返回、迟到回调、重复点击、关闭整条路径、直接入口、重建 key、
无效及反向恢复数据、100 次往返和退出确认。

`menu-navigation-regression.py` 使用实际 UI 输入与窗口断言，覆盖：

- 菜单直接返回；设置经系统/工具栏返回菜单，再返回浏览器，保留菜单滚动位置。
- 书签、历史、下载、网站设置、开发工具返回菜单时只保留一个弹层；关于页没有重复开发入口。
- 设置选项、后台恢复、字体触发的 Activity 重建及拖动关闭。
- 24 轮快速返回（30/80/160/300 ms 间隔）及打开设置后立即返回（0/15/50/100 ms）。
- 退出确认窗口内的输入序列、外部网址打断设置，最后真实点击网页链接检查触摸可用。

`settings-back-regression.py` 另覆盖六类设置、嵌套选项、宽屏两栏、旋转和真实边缘返回。
输入辅助程序返回实际注入回执与耗时；没有回执时失败，不自动重试可能已送达的返回。

```bash
python3 validation/qa-server.py --apk PureBrowser-v0.7.1-release.apk
python3 validation/setup-ui-probe.py emulator-5554
python3 validation/menu-navigation-regression.py --serial emulator-5554
python3 validation/settings-back-regression.py --serial emulator-5554
```
