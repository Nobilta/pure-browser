# Material 3 界面审查

2026-09-13，0.8.0。范围是浏览器自带界面；网页、WebView 内建控件和 Android 系统选择器由各自提供方绘制。
当前实际设备、截图、触摸结果及未验证范围见 [回归报告](../EMULATOR_TEST_REPORT.md)。

| 界面 | 共用规范与本次处理 |
|---|---|
| 全局主题 | Material 3 字型、shape、surface/container 与成对前景；Android 12+ 动态配色，旧系统沿用统一浅/深色表 |
| 首页地址栏 | 移除导航页无交互的主页占位图标；文本区域保持可编辑，右侧 48dp 扫码操作；网页安全信息与刷新/停止保留 |
| 地址栏、底栏、查找与建议 | 复用原输入/焦点规则和 MD3 色阶；软键盘、清除、补全、上下地址栏与硬件返回维持单窗口所有权 |
| 菜单与标签 | 共用 `BrowserSheetHeader`，64dp 最小标题区、48dp 图标操作、统一 titleLarge；底部弹层增加 12dp 内边距及顶部安全区域后的 16dp 间隔，菜单标题固定，标签预览采用主题圆角 |
| 书签、历史与下载 | 同一标题、搜索与操作组件；历史分组底色与页面一致，下载空态改为下载图标，列表在剩余高度滚动并保留标题 |
| 设置与选项 | 共用标题，内容使用短过渡；搜索引擎、下载目录、主页选项合并整行单选语义，消除重复 RadioButton 点击目标 |
| 网站设置与管理 | 同一标题与搜索，表单/列表固定滚动边界，保存/取消区保留；长来源与权限说明位于滚动区域 |
| 过滤与脚本管理 | 共用标题、Card/Switch/AlertDialog，过滤列表的背景色与父页一致；操作与显示状态继续来自仓库 |
| 开发工具 | 标准 PrimaryTabRow、主题语法色、等宽源码/日志；网络使用 FilterChip、统一搜索框及状态菜单；按需排版与后台解析避免阻塞输入 |
| 扫码与文本结果 | MD3 全屏页、标题、按钮与反馈；相机画面采用主题圆角，取景框受预览短边约束，横屏分栏，大字体操作区可滚动；文本支持选择/复制，拒绝相机授权可选图 |
| 证书、网页提示与 HTTP 登录 | 统一 MD3 AlertDialog；移除证书提示散落的手写字号，错误区域使用 errorContainer/onErrorContainer，密码输入保持遮罩 |
| 清理数据与外部跳转 | MD3 对话框、整行单选/复选语义，长内容可滚动；旧权限回执与来源校验保持 |
| 投屏与远端控制 | 普通浏览器投屏页增加固定标题，内容受剩余高度约束；全屏内嵌投屏继续复用原面板与设备/媒体选择 |
| 全屏媒体 | 沿用 0.7.4 MD3 控件、深色动态配色和同窗口浮层，不修改视频区域，安全边距只作用于控件 |

统一过渡以 300ms MD3 标准曲线进入，150ms 窗口退出，设置内容为 200ms；只改变图层透明度和位移，
不会逐帧改变列表高度。系统动画缩放为 0 时自动跳过 Compose 和窗口动画。
菜单路径始终只有一个 Dialog 和一个内容所有者，子页切换保持不透明底板，旧页面不会同时挂载或抢占返回。
表单和列表继续关闭弹性拉伸，弹层没有拖动锚点；按钮、系统返回及外部区域关闭保持原有语义。

源码解码、着色和网络搜索在工作线程运行；单个源码排版块至多 768 个 UTF-16 字符/12 行，
总字符与块数都有上限。控制台也改为惰性列表。日志只有选中页发布快照，切到源码不持续处理网络/控制台的重组。
这些措施针对实际发现的同步排版与重复计算，未以增加 Rust/JNI 替代 Android 的布局和生命周期。
