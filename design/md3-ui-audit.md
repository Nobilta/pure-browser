# Material 3 界面审查

2026-09-11，0.7.0。沿用此前对 `ui/` 浏览器界面组件和原生全屏播放器的审查，
本轮进一步复核错误状态、数据操作反馈、面板订阅及下载图标。
检查主题颜色与前景配对、字型、圆角、触摸区域、选择语义、弹层返回、暗色和小屏可达性。

| 界面 | 发现与处理 |
|---|---|
| 全局主题 | 补全浅深色 surface/container、secondary、tertiary 颜色，避免旧系统混入默认紫色；Android 12+ 保留动态配色；所有底部弹层显式同步应用主题的系统栏图标，修复系统浅色而应用深色时的黑色图标 |
| 地址栏、底栏、查找 | 图标操作触摸区域统一为 48dp，底栏 64dp；保留输入字体放大适配和安全区域；新文档清空上页查找 |
| 安全信息 | 使用有浅深色对比度的语义色；用户忽略证书错误后，刷新/重访仍显示危险连接，错误区域使用 errorContainer/onErrorContainer；日期不代表信任结论 |
| 搜索建议 | 类型标签、分隔线和文本改用成对的主题色与 MD3 字型 |
| 首页与快捷入口 | 占位图标使用主题色，卡片采用主题圆角；现有 MD3 编辑窗口与系统选图流程保留 |
| 菜单、上下文操作 | 使用 MD3 弹层和统一 BrowserActionRow；菜单路由保留父级，返回恢复滚动位置，只挂载栈顶；手柄位于系统安全区域，拖动关闭不会拉出通知栏 |
| 标签、书签、历史 | 卡片采用主题圆角与 tonal 容器；保留统一搜索框、条目菜单、分页及删除确认；删除成功提示等待数据库确认，无痕正确显示显式保存的书签 |
| 设置 | 选项 → 分类 → 设置首页 → 菜单 → 浏览器逐级返回；管理弹层停用父级返回，旧关闭回调不能影响新页面；宽屏保持一致，颜色、字型跟随主题 |
| 下载 | 使用下载/文件/暂停图标表达状态，合并失败/暂停的重试操作区；沿用 MD3 列表和删除确认；系统文件授权由 Android 提供 |
| 网页提示与 HTTP 登录 | 由旧平台 AlertDialog 改为 Activity 持有状态的 MD3 Dialog；关闭和销毁恰好回答一次，密码遮罩 |
| 广告规则与脚本管理 | MD3 Card/Switch/AlertDialog，显示实际更新状态和安装预览；开关有读屏名称，旧 WebView 仍可关闭已启用脚本 |
| 开发工具 | 标准 TopAppBar、PrimaryTabRow、拖拽把手和 tonal 执行按钮；消除重复系统栏留白，标签至少 48dp；主题容器与等宽代码字型；横屏键盘采用紧凑输入布局 |
| 视频倍速、投屏 | 倍速使用可滚动 MD3 单选弹层；投屏候选有单选语义，发送期间禁用重复选择；网页新增 MD3 FAB |
| 全屏媒体 | 保留适合视频背景的黑白对比，统一圆角和至少 48dp 控件；手势只给短暂数值反馈，避免说明遮挡画面 |

网页自身的 HTML/CSS、WebView 内建网页控件、Android 权限和文件选择界面分别由网站、WebView 或系统绘制。
浏览器在无法接管网页内或全屏视频时保留原界面，避免两套播放器互相覆盖。

开发工具同时修复了交互问题：切换标签保留窗口内的命令草稿及执行结果，执行后自动滚动到最新结果；源码改为按需、有界读取，
不再在只查看控制台时获取整个网页 DOM。横屏键盘收起后恢复完整标题、标签和清空操作。
0.4.1 仅在开发工具可见时订阅日志；关闭期间仍由进程内有界存储接收网页日志，重新打开可查看。
下载和投屏面板也按可见性订阅状态。

自动资源校验、模拟器主题/语言/横屏/大字截图，以及播放器真实触摸结果见
[回归报告](../EMULATOR_TEST_REPORT.md)。本次并未将静态代码审查描述为全平台设计认证。

## 0.5.0 新增界面

网站偏好、独立权限对话框、最近关闭/撤销、书签迁移和远端播放控制沿用主题组件。
网站权限按钮具有读屏名称，系统栏跟随主题。网站来源与说明纳入滚动区，避免长地址、大字体或横屏挤掉设置操作；底部按钮等高。
新增能力通过实际触摸、网站遥测、SAF 文件及文件哈希验证；150% 字体的横竖屏结果见
[当前回归报告](../EMULATOR_TEST_REPORT.md)。

## 0.7.0 下载与内嵌视频

完成的下载行直接调用系统文件打开能力，无独立打开/安装按钮。内嵌视频控件使用独立 Shadow DOM，
正常尺寸显示播放、静音、进度、倍速、全屏和恢复；160×90 的紧凑布局隐藏时间与静音，防止按钮越出画面。
网页控制层无法隔离时恢复原样。移除的功能及依赖不再保留入口或验证清单。
