## 验证范围

被测产物为本地构建的 0.13.5（versionCode 33）签名 Release，SHA-256 `b36d110b52dc6453c0d0b0828c1f915f181a41d29d76845f0f459878040e30ec`
（与 `SHA256SUMS`、`outputs/release/package-info.json` 一致）。设备为 API 37 的 `google_apis`
arm64-v8a 模拟器（冷启动、数据重建、系统默认区域设置、font scale 1.0）；签名、zipalign、R8 与 ABI 校验在
打包时通过。下面逐项给出的是实测数值。

- 遮罩与面板不一致的定位（逐帧录像，10 倍慢放后按 60fps 抽帧，用内容相位匹配量面板位置）：
  修复前面板走到 **81%** 行程时遮罩只到 **19%**（60Hz 下第一帧就推进约 42% 的行程），
  即一块明亮面板先闪到位、背景随后才暗下来——这就是残留的「闪一下」。修复后两者由同一条进度算出，
  比例恒为 `alpha = 0.32 × 面板进度`，不可能再走散（结构性保证，不是调参）。
- 遮罩自身的渐变在慢放下实测单调：243.8 → 165.7（= 1 − 0.32，正是设计强度），无回弹、无台阶。
- 打开面板不会改变页面视口：给 WebView 容器加了尺寸与 inset 监听后打开面板，两者都没有回调
  （即页面没有因面板出现而重新布局）。
- 设备上打开面板后 dump 全部窗口，整份 dump 里不再出现 `DIM_BEHIND`。
- 停稳后的面板位置逐像素不变：内容列边界 `[0, 210, 1080, 2337]`。
- 自动检查：Android/JVM **533 项**测试通过；Rust 与 Node 测试、三语言资源一致性、Rust fmt/clippy 与
  Android lint（0 error）通过。
- 模拟器回归：改动涉及的 12 个阶段在两个 scope 内全部通过，`apkSha256` 都等于上面的交付包：
  `omnibar`、`motion-gesture`、`motion-interruption`、`menu-navigation`、`security`、`download`（scope A）
  与 `browser`、`features-dialogs`、`settings-back`、`settings`、`home-shortcut`（scope B）；
  `developer-tools` 在 scope A 中因子述环境退化失败一次，冷启动后在 scope B 中通过。
- 环境退化的重复：同一交付包在连续跑了数小时、adb 注入输入由 19ms 退化到 1.4s 的模拟器上
  `developer-tools` 连续失败两次（横屏 + 输入法后找不到 Run），冷启动模拟器后同一交付包通过。
  该阶段的旋转断言取的是无障碍树第一个节点（状态栏窗口 1080×136，永远宽大于高），
  证明不了旋转是否生效，会在重排未完成时就去点 Run——这是该阶段的弱点，与本版改动无关。
- 未覆盖：真机（扫码预览方向、实体接收器投屏、真实账号登录）、升级数据保留的专项断言、
  非 arm64-v8a 以及低于 API 30 的设备。完整 46 阶段矩阵只跑了改动相关的 12 个阶段。
- 本机局限：模拟器是软件 GPU，面板打开时每秒只渲染约 1–3 帧（已验证：1 倍速录像里整个 300ms 入场
  只落在 1 帧内），因此模拟器无法判断动画本身的顺滑度；上面的结论都来自可量化的量
  （位置、亮度、窗口标志、视口回调），手感仍以真机为准。

## 本版未覆盖的动效

- 其余原生 Material 3 `AlertDialog` 仍用平台的窗口动画。Android 的对话框动效由窗口承担，
  它把遮罩和对话框表面作为一体一起淡入；应用自己实现的 `BrowserAlertDialog` 只驱动表面，
  遮罩由窗口立即出现，因此不把它们统一迁移反而更接近平台一致的行为。
- 设置页在窄布局下从分类返回列表时，进入的一侧有动效，被移除的一侧仍是即时消失。
  改成两侧同时动画需要保留离开的窗格，属于设置页的组合结构调整。
- 各处"列表 ↔ 空状态"的内容切换（下载、标签页、网络日志等）仍是即时切换，未套 `AnimatedContent`。
- 安全指示图标的图标与颜色保持即时切换，这是刻意的：它描述的是当前页面的安全状态，
  淡出上一个页面的锁形图标会在渐变期间显示一个错误的结论。
- 下拉关闭的"甩出速度"判定没有自动化：速度来自最后约 100ms 内采样点的拟合，
  而本机 adb 注入单个事件的耗时与这个窗口同量级，无法提供与手指同密度的采样，该路径手工核对。
