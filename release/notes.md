# Pure Browser 0.10.0

这一版把界面动效收敛成一份规格，并让开发流程在 macOS、Linux 和 Windows 上使用同一套命令。

- **面板动效统一**：进入 300ms 减速停稳、退出 200ms 加速离开、页内切换 250ms 位移，全部来自同一份
  规格表。关闭面板时显示的是真实页面而不是空窗口；退出动画进行中重新打开会从当前位置继续，不再
  重播入场。全屏页（设置、书签、扫码）改为 32dp 偏移加淡入淡出，不再是整屏滑动。
- **设置页**：分类切换有明确方向，每个分类记住上次的滚动位置，表头标题随页面平滑过渡。
- **地址栏**：顶部与底部使用同一套显示/隐藏节奏，各自朝所在屏幕边缘展开收起。
- **列表增删**：标签、下载、书签删除时该项淡出、相邻项滑到新位置，新增项淡入；下载进度等持续更新
  不会重播动画。
- **对话框**：网页对话框、删除确认、更新提示、清理浏览数据、系统登录说明、输入对话框补上进场动效，
  布局与颜色仍沿用 Material 3 的对话框。
- **开发流程**：macOS、Linux、Windows 共用同一套构建、单元测试与模拟器回归命令，CI 在三平台运行；
  x86_64 主机也能运行模拟器回归（需测试签名的 x86_64 测试包）。

## 验证范围

以下摘要对应 v0.10.0 正式 APK（versionCode 20），文件校验和见 Release 附件。

- 三语言资源 639 项、Node 55 项、Rust 57 项、Android 单元测试 336 项全部通过；lint 为 0 errors；
  ubuntu、macOS、Windows 三平台 CI 通过。
- Android 17 / API 37 ARM64 模拟器：omnibar、resident、browser、features-dialogs、settings、layout、
  bookmarks、download、update-launch、menu-navigation 十个阶段通过。
- 本版没有做真机动效测量：帧率、掉帧和高刷新率屏幕的结论需要真机重复采样，模拟器结果不能代替。
- 实体设备、DLNA 接收器画面和真实账号登录未验证；在实体设备上从上一正式版覆盖安装也未执行。
- 0.9.1 能否发现本版的线上实测结果见下一条说明。
