# Pure Browser 0.12

### 新增

- 「浏览器全屏」：隐藏系统栏与工具栏沉浸浏览，保留「浏览器操作」浮动按钮，支持返回键、F11/Esc 和视频全屏优先级。
- 设置导出为完整备份：除设置外还包含书签（含文件夹结构）和浏览历史，可在其他设备预览后合并导入，重复导入不会重复添加。
- 下载开始前确认文件名、来源与保存位置；已完成的记录可「重新下载」新副本并保留旧文件。
- 长按保存图片时就地确认「保存副本」，不再自动打开下载管理。
- 地址栏在线搜索联想：百度、Google、Bing、DuckDuckGo 内置，自定义引擎可另填联想地址，可关闭，无痕默认关闭。
- 地址栏粘贴文本时可直接打开其中识别出的网址。
- 无痕开关退出后保持，下次启动进入新的无痕会话。
- 下载通知按系统真实状态引导授权；网站设置损坏时明确提示并支持确认重置。

### 修复

- 修复自动填充的宿主绑定：WebView 改由 Activity 创建，实例不再跨 Activity 复用。
- 修复登录弹窗期间来源页被暂停请求或销毁：保留窗口关系与页面状态，支持后台弹窗、嵌套弹窗和无痕模式。
- 修复百度中文联想的 GBK 解码；无效编码不再显示或缓存。
- 修复旧书签查询覆盖刚完成的添加、删除结果，避免当前页星标闪回。
- 修复下载拒绝条目移除后无法重新请求；拦截列表满时优先保留新请求。
- 修复无痕清理未完成就加载页面，以及新无痕会话命中上次会话下载记录。
- 修复设置导入：导出等待订阅加载完成，导入后补齐已启用订阅缺少的规则，权限「记住」失败不再把允许反转为拒绝。
- 修复 WebView 内存不足：回收最老的驻留页后重试，极端内存压力时释放后台窗口组。
- 修复网站桌面模式反复扫描全部网站。
- 源码高亮词法分析迁入 Rust：修复截断处拆分表情字符，修正 ½、Ⅳ 等字符的着色归类。
