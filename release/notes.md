# Pure Browser 0.11

- 无痕清理阻止页面提前加载，重建或关闭后在同一进程内重开仍等待；失败可重试或退出。新的无痕会话不再命中旧会话下载记录。
- 下载拒绝条目移除后可重新请求，保留文档弹窗预算；满列表优先保存新拦截请求，移除已有任务入口不会重复自动打开下载管理。
- 导出等待订阅初始化；导入后后台下载已启用自定义订阅缺少的首次规则，显示未下载或更新失败状态并支持重试。
- 网站权限的记住操作失败时保留本次允许/拒绝选择及 Android 系统授权约束，不覆盖损坏原始数据。
- 长按保存图片就地确认新副本，进行中/暂停任务只轻提示；不自动打开下载管理，也不消耗网页自动弹窗预算。
- 导入预览为版本、时间和内置订阅设置长度/数量上限；超限文件提前拒绝，显示文本和列表在拼接排版前截断。
- 新增浏览器沉浸全屏、无痕开关持久化、粘贴文本提取网址、在线搜索联想及设置导入导出。
- WebView 使用所属 Activity 初始化；登录弹窗保留来源页及后台回调，支持普通/无痕和嵌套窗口。极端内存压力下释放后台窗口组，保留标签地址供重新加载。
- 修复百度 GBK 中文联想乱码；响应按声明编码严格解码，无效数据不显示、不缓存。请求取消、总超时与无痕会话结束会作废迟到响应。
- 下载先确认文件名、来源、已知大小与保存位置。确认、自动弹窗预算和拦截列表按标签文档隔离；最多保存 5 条拦截记录，额外事件显示计数及恢复方式，首次拦截和首次溢出各提示一次。
- 重新下载生成独立副本，失败或取消也保留旧文件与记录；普通任务重读当前 Cookie，活动任务继续合并。重复请求保留手动操作入口。
- 通知授权仅由设置入口主动触发；迁移旧申请记录，永久拒绝后可直接进入系统通知设置。
- 全屏退出立即生效，写盘失败时本次会话仍保持退出；启用失败恢复原偏好，交错请求不会被过期结果覆盖。设置搜索支持定位全屏开关。
- 导入前统一校验订阅地址、重复项与内置清单冲突、嵌套类型及搜索引擎序列化总量；非法配置整体拒绝。合法文件按分组确认保存，失败恢复该组原值并说明分组名称。
- 损坏的网站设置拒绝普通写入，权限清理不会覆盖原始内容；源码高亮迁入 Rust，并附固定 JDK 基线的字符表生成/比对工具。

## 验证范围

被测产物为本地 v0.11（versionCode 23）签名 Release；附件保存 APK 大小和摘要。

- Android/JVM 480 项、Rust 61 项、Node 59 项测试通过；三语言 730 项资源及格式参数一致。
- Rust fmt/clippy、R8、APK v2 签名及 16 KiB zipalign 校验通过；Android lint 为 0 错误、34 警告、2 提示。
- 本次新增 14 项 JVM 回归覆盖清理等待/失败重试/窗口替换、下载会话结束、拒绝恢复与拦截优先级、导出初始化、导入首次规则失败后重试生效，以及 DuckDuckGo 协议和深嵌套响应后继续请求。
- 字符表生成器已逐项核对全部 65,536 个 BMP 值，和 JDK 26.0.2.1 一致。
- 新回归覆盖 GBK 与无效编码、重新下载失败/取消保留旧文件、当前 Cookie、标签状态与溢出、导入前整体拒绝、通知历史迁移及全屏偏好写入失败。
- 本次按要求未运行模拟器或真机。Bitwarden 实际填充、Google/X 登录、不同 Android/WebView 版本、真实 Chromium 窗口通信及系统内存压力仍待设备验证。
- DuckDuckGo 端点与格式按官方配置和公开客户端源码核对，本机直连失败；本地协议测试不代表远程网络可用性。
