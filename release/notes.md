## 0.19.2 本地测试包验证范围

被测产物：`PureBrowser-v0.19.2-release.apk`（versionCode 73），本地签名 Release，尚未发布。

- 自动化：789 项 JVM、129 项 JavaScript、69 项 Rust、14 项发布工具测试全部通过；本地化、Clippy、Lint（无错误，保留建议警告）、R8、APK 签名与对齐检查通过。
- Android 14 / API 34 ARM64 模拟器，WebView 113.0.5672.136：直接与跨站 Basic 登录、凭据复用、接受证书后的播放与拖动、证书复用通过；分段 403 保留页面、A→B→A Cookie 对照定向回归通过。主文档 HTTP 拒绝、离线、拒绝证书和读取中断 4 项回归通过。
- Android 17 / API 37 ARM64 模拟器，WebView 145.0.7632.218：媒体网络完整 7 项回归通过，覆盖直接与跨站 Basic 登录、凭据/证书复用、分段失败保留页面和 A→B→A Cookie。书签 9 项回归通过，覆盖文件夹排序、多选、拖动取消、跨多行与跨分页拖动、持久排序和图标缓存；导航恢复与普通分段下载通过，下载文件 SHA-256 与服务停止状态符合预期。
- 两台模拟器均通过 11 项媒体回退/附件用例：来源策略、HTML 回退、认证提示、一次性与跳转附件、gzip、未知长度、确认超时和显式重试。保存文件校验一致，正常确认保存只有一次 GET，超时期间不自动重请求。
- WebView 145 来源矩阵 9 个场景通过：直接、重定向、origin、no-referrer、跨站 CDN、1 GiB、2 GiB 边界与超过边界的定位、无痕播放；覆盖播放/拖动/刷新、返回来源页和离开媒体页后不复用旧 Referer。
- JVM 另外覆盖计费网络限制、5 秒并发等待上限、过期与点击竞态、进程中断后保持暂停、证书/凭据的站点范围与会话清除，以及损坏书签数据保留上一次有效视图。

书签跨分页用例在双模拟器并发负载下未在固定 13 秒内到达第 50 行，独立重跑通过；其余书签断言未变。

未验证：实体设备、其余 Android/WebView 版本、Digest/代理认证与防盗链的组合、真实 DLNA 接收设备。媒体格式兼容性仍受系统 WebView 与设备解码器限制。

详细日志、服务器请求与模拟器结果保存在忽略目录 `validation/results/`；产物校验值和签名信息由 `outputs/release/` 的发布附件记录。
