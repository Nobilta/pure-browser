# Pure Browser 0.10.1

- 网页等待响应头或连接挂起时立即显示加载进度（未知时长用不确定进度条），停止加载后及时结束提示。
- 内置报错页成为唯一的错误界面：连续失败与重试期间保持显示，新文档上屏后才收起，不再与网页自带错误页来回切换。
- 打开菜单、多标签管理等面板不再"跳"：改为等窗口完成首次布局后再播放入场动画，位移完整、不再被窗口创建过程吃掉。
- 主页仪表盘、投屏入口、查找栏、页面恢复页、地址栏建议与无痕提示补上淡入与展开动效，书签和下载的选择工具条同样处理。
- 倍速改为 0.5×–5× 连续调节（滑杆刻度即 0.1 档，面板不再因选择而关闭）；长按临时加速默认 2×（设置可改 3×），按住继续上滑可按剩余行程升到 5×，松手恢复。
- 全屏显示控件时，顶部同时显示时间与电量；电量低于 20% 且未充电时转为告警色，时间保持常色。
- 视频卡顿时显示"正在缓冲"与实时加载速度：页面使用 MSE 播放时按该视频自身的传输计数，否则退回整个应用的接收速率。
- 下载管理支持长按多选后批量删除；删除运行中的任务会先停止传输、等待写入结束，再清理记录与临时文件，不再残留失效任务。

## 验证范围

以下摘要对应 v0.10.1 签名 APK（versionCode 21），文件大小、签名与校验和见生成的 Release 附件。

- 三语言资源 644 项、Node 59 项、Rust 57 项、Android 单元测试 343 项通过；Rust fmt/clippy、Android lint、R8、APK 签名和 zipalign 校验通过。
- Android 17 / API 37 ARM64 模拟器，WebView 145.0.7632.218：页面恢复回归通过，覆盖延迟响应头、地址导航、网页链接、POST 表单、连续失败、成功重试、停止加载及停止后再次提交表单。
- 同一签名 APK 的地址栏、常驻标签和下载回归通过：覆盖顶部/底部输入、建议、旋转保留草稿、多标签恢复、真实分段下载校验及服务结束。
- 标准视频回归通过：覆盖倍速滑杆拖动到 0.5× / 1.5× / 5×、长按临时加速、后台恢复、播放/定位/亮度/音量手势、锁定与系统返回、退出全屏还原，以及网站级增强控件开关。
- 下载单元测试覆盖取消活动传输、等待写入结束、临时文件清理，以及暂停与删除并发。
- 未验证真机、其他 Android/WebView 版本、实体 DLNA 接收器和真实账号登录；模拟器结果不能代替这些覆盖。
